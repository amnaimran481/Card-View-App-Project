#  **Card View App** 

A modern Android application built using **Java** and **RecyclerView** that displays a collection of technology courses in attractive card layouts. Users can browse course information and view detailed course descriptions through an interactive interface.

## Features

-  Clean and responsive Card View design
-  RecyclerView implementation for efficient data display
-  Course images and visual content
-  Course ratings display
-  Detailed course information screen
-  Intent-based navigation between activities
-  Modern Material-inspired UI

## How It Works

1. The application loads a list of technology courses.
2. Courses are displayed using RecyclerView cards.
3. Each card contains:
   - Course Image
   - Course Title
   - Course Description
   - Rating
   - Enroll Button
4. Clicking the **Enroll** button opens a detailed course page.
5. Users can view complete course information and enroll in the selected course.
